## 4. SetCentrum: найти кассы магазина

1. Открыть [дашборд](http://172.16.0.85:8092/dashboard).
2. В поле **«Магазин»** ввести номер ТО (например, **715**).
3. В таблице отобразятся кассы: номер, тип **(POS / SCO3 / Touch)**, **IP**, версия Set10, дата последней перезагрузки.

Использовать при заявках «какой IP у кассы N», массовые сбои по магазину, сверка версии.

---

## 5. SetConsole: удалённое подключение (VNC)

1. Запустить **SetConsole** («Кассы SetConsole»).
2. В строке нужной кассы указать **номер магазина**, **номер кассы**, **IP** (из SetCentrum или заявки).
3. При необходимости нажать **«Пинг»** — зелёный статус означает доступность узла.
4. В колонке **«Удалённый контроль VNC»** нажать кнопку **`<>`** напротив IP — откроется сессия на экран кассы.

**Типовые сценарии по VNC (без выезда):**

- Проверить **актуальную цену** или наличие товара на кассе, если магазин сообщает «не та цена» / «товар не загружен».
- На КСО: **«Найти товар»** → поиск по ШК или наименованию → сверить цену с Fusion / Set10.
- Убедиться, что на кассе **нет открытого чека** перед прогрузкой (см. [KB id=702](https://support.willesden.by/front/knowbaseitem.form.php?id=702)).

Настройки VNC в SetConsole (качество, таймаут, версия клиента) сохраняются отдельно; для диагностики обычно достаточно **Full color** и клиента **«Новая»**.

## 6. Режим администратора на КСО

Для сервисных действий на экране КСО (не режим покупателя):

1. На основном экране КСО нажать **скрытые области** в правом верхнем углу в комбинации: **1 → 1 → 2 → 1** (две зоны «1», затем «2», затем снова «1»).
2. Ввести пароль администратора: **324012**.
3. После входа доступны сервисные функции кассового ПО (очистка, обслуживание — по регламенту САКПО).

**Важно:** пароль и комбинация — внутренние; не передавать в переписку с магазином в открытом виде, если политика этого требует.

## 7. Прогрузить товар в оборудование (весы, кассы и др.)

**Сектор:** точечная прогрузка — **СРИСиС**; после прогрузки на кассе ждать **очередь Set10** (**САКПО** / ТО). Алгоритм совпадает с каталогом **п. 17**.

### 7.1. Запуск загрузки

1. **LS Fusion** → **«Рабочий стол»** → **«Розничная торговля»** → **«Обновление розничных цен»**.
2. В поле склада / наименования выбрать **нужный магазин** (склад ТО).
3. В поле **«Штрихкод»** ввести **ШК** товара.
4. Внизу экрана в фильтре **«Ценники и оборудование»** выставить **«(Все)»** — всегда для точечной прогрузки.
5. В таблице отметить галочками **все строки товара**, которые нужно прогрузить.
6. Перейти на вкладку **«Загрузки»** (нижняя панель).
7. Нажать **«Загрузить в оборудование (с товарами)»**.

Появится сообщение вида: *«Принято к загрузке в оборудование: SET10 … — N товаров»* — нажать **«Закрыть»**.

### 7.2. Контроль выполнения

1. **«Оборудование»** → форма **«Загрузки прайса в оборудование»**.
2. Выбрать **тот же склад** (магазин).
3. Найти строку своей загрузки (группа **SET10**, модель касс, класс «Загрузка прайса в кассы»).
4. Дождаться галочки в колонке **«Загружено»** — после этого данные на кассах/КСО обновятся по очереди Set (обычно **10–15 минут**; на кассе не должно быть открытого чека).

В нижней части формы видны ШК, цена и наименование позиций в задании.

## 8. Выгрузка пик-листа на кассы

**Кто выполняет:** в штатном режиме **торговый объект (ТО)** сам; УИТ (**САКПО**) — при ошибках или неактуальных данных ([KB id=831](https://support.willesden.by/front/knowbaseitem.form.php?id=831)).

1. **LS Fusion** → **«Рабочий стол»**.
2. В дереве слева: **«Товары»** → **«Выгрузка Пиклистов (все устройства)»**.
3. Отметить нужные **категории** товаров (или выбрать позиции в списке справа).
4. Нажать **«Выгрузить»** (при необходимости — **«Выгрузка (планшет)»** для планшетного сценария).
5. Дождаться завершения; при выгрузке **с картинками** клиент **LS Fusion** должен быть запущен локально (не «пустая» Citrix-сессия).

После пик-листа на кассах — **очередь Set10**; при массовых «данные не актуальны» см. [KB id=702](https://support.willesden.by/front/knowbaseitem.form.php?id=702) (очистка кассы, «Новая касса» при версии ≥ 10.5.2.0).

## 9. Разводка по секторам (кратко)

| Задача | Сектор |
|---|---|
| IP кассы, VNC, перезапуск модуля, SetConsole | **СПП** / **САКПО** (кассовое ПО) |
| Точечная прогрузка товара, «Обновление розничных цен» | **СРИСиС** |
| Пик-лист, очередь Set, «Новая касса», логика на кассе | **САКПО** (+ ТО) |
| Не отвечает железо кассы, экран, питание | **СОКС** |
