# AdminPanel — единый шлюз приложений сектора ТП

Оболочка с авторизацией и индивидуальными правами доступа. При запуске сама поднимает встроенные приложения (**Инструкции**, **Учёт ТМЦ**, **GLPI** и др.) как внутренние сервисы на `127.0.0.1` и отдаёт их через защищённый прокси.

## Требования

- Node.js 18+
- Рядом с этим репозиторием должны лежать проекты:
  - `D:\Проекты\Instructions`
  - `D:\Проекты\Учет ТМЦ`
  - `D:\Проекты\Torcy`
  - `D:\Проекты\GLPI`
  - `D:\Проекты\KnowledgeBase`

## Установка

```bash
cd D:\Проекты\AdminPanel
npm run install:all
npm run install:apps
```

## Сборка встроенных приложений (обязательно перед первым стартом)

Клиенты встроенных приложений собираются с префиксом пути (`/apps/instructions`, `/apps/tmc`):

```bash
npm run build:apps
npm run build
```

## Запуск

Достаточно запустить AdminPanel — дочерние приложения стартуют автоматически:

```bash
npm start
```

Откройте в браузере: [http://localhost:4000](http://localhost:4000)

### Режим разработки оболочки

```bash
npm run build:apps
npm run dev
```

- UI оболочки: [http://localhost:4173](http://localhost:4173)
- API/шлюз: [http://localhost:4000](http://localhost:4000)

## Учётная запись по умолчанию

При первом запуске создаётся администратор:

| Параметр | Значение по умолчанию | Переменная окружения |
|----------|------------------------|----------------------|
| Логин    | `admin`                | `ADMIN_USERNAME`     |
| Пароль   | `admin`                | `ADMIN_PASSWORD`     |

Рекомендуется сразу сменить пароль.

Дополнительно:

- `JWT_SECRET` — секрет подписи сессии
- `PORT` — порт шлюза (по умолчанию `4000`)
- `HOST` — адрес шлюза (по умолчанию `0.0.0.0`)
- `SUPERVISOR=0` — не поднимать дочерние процессы (только оболочка)

## Роли и доступы

- **Администратор** — видит все приложения, управляет пользователями и правами.
- **Специалист** — видит только приложения, выданные ему индивидуально (не только по роли).

Админка: «Пользователи» и «Управление приложениями».

## Добавление нового приложения

1. Разработайте приложение как отдельный сервис (Express + клиент).
2. Добавьте запись в [`config/apps.json`](config/apps.json).
3. Соберите клиент с `BASE_PATH=/apps/<id>`.
4. Перезапустите AdminPanel.
5. Выдайте специалистам доступ в разделе «Пользователи».

Контракт приложения:

- health endpoint (например `/api/health`);
- bind на `HOST`/`PORT` из окружения;
- клиентские запросы API с учётом `import.meta.env.BASE_URL`.
