# FAQ — частые вопросы о GLPI Cleaner

Ответы на вопросы вида «а можно ли…» и «а что будет, если…».  
Технические сбои смотрите также в [USER_GUIDE.md](USER_GUIDE.md) (раздел 7) и [CHEATSHEET.md](CHEATSHEET.md).

---

### 1. Можно ли удалить только закрытые заявки, а решённые оставить?

Да. Во вкладке «Правила» в поле статусов укажите только `6` (закрыта). Значение `5` — решена.

### 2. Что будет, если оставить Dry-Run включённым навсегда?

Программа будет только считать и показывать подходящие заявки. Удаления не будет — даже по расписанию. Для реальной очистки Dry-Run нужно выключить и сохранить `config.json`.

### 3. Можно ли восстановить заявки после удаления?

- Если **Force purge выключен** — заявки попадают в корзину GLPI; администратор может восстановить их из интерфейса GLPI (если политика организации это позволяет).
- Если **Force purge включён** — только из резервной копии базы данных.

### 4. Удалит ли программа заявки младше года, если я ошибся в настройках?

Перед удалением каждая заявка проверяется ещё раз по дате и статусу. Если дата открытия **не старше** порога — заявка пропускается. Тем не менее всегда сначала делайте Dry-Run и проверяйте таблицу.

### 5. Можно ли запускать программу на двух компьютерах одновременно?

Технически да, но не рекомендуется: оба клиента могут пытаться удалять одни и те же заявки. Лучше один сервер/служба.

### 6. Нужен ли Python на компьютере, если есть `.exe`?

Нет. Готовый `.exe` уже содержит нужное окружение. Python нужен только для запуска из исходников или для сборки через `build_windows.bat`.

### 6a. Не вставляется текст из буфера (Ctrl+V) в поля

Частая причина — русская раскладка клавиатуры. В актуальной версии работают:
- **Ctrl+V** по физической клавише V (и при русской раскладке);
- **Shift+Insert**;
- **правая кнопка мыши** → «Вставить».

Обновите `GLPI_Cleaner.exe` из папки `dist` после пересборки.

### 7. Можно ли править config.json, пока программа работает?

В режиме `--daemon` конфиг перечитывается перед каждым запуском по расписанию. В GUI надёжнее нажать «Сохранить» и при необходимости перезапустить планировщик.

### 8. А если URL указать без `/apirest.php`?

Подключение, скорее всего, не сработает. Нужен полный адрес API, например:  
`https://support.willesden.by/apirest.php`.

### 9. Можно ли ограничить удаление одной категорией?

В `config.json` есть поле `category_ids` (массив числовых id категорий). Если список не пустой, заявки вне этих категорий пропускаются (когда id категории удаётся определить из ответа API). Для новичков проще сначала работать только по статусу и возрасту.

### 10. Что безопаснее: служба с `--daemon` или Task Scheduler с `--once`?

Для новичка на Windows часто проще **Планировщик заданий** с `--once`: меньше «фоновой магии». Служба удобна, если нужен постоянный процесс и расписание внутри `config.json`. Кнопка **«Запустить в фоне»** в GUI делает то же, что `--daemon`, без ручного ввода команд.

### 10a. Можно ли закрыть окно и чтобы очистка продолжалась?

Да. Нажмите **«Запустить в фоне»** — запустится отдельный процесс. После этого окно можно закрыть. Либо сверните в трей («Свернуть в трей»), тогда процесс окна останется, но будет скрыт.

### 10b. Чем «планировщик в окне» отличается от «Запустить в фоне»?

| | Планировщик в окне | Запустить в фоне |
|--|--------------------|------------------|
| Нужно открытое окно | Да (или трей) | Нет |
| Отдельный процесс | Нет | Да (`glpi-cleaner-cli`) |
| Для сервера | Неудобно | Удобно |

### 11. Видит ли программа заявки всех организаций (entities) в GLPI?

Она работает от имени пользователя User-Token и видит то, что видит этот пользователь (активная организация и права). Если заявок «мало» — проверьте entity и права профиля в GLPI.

### 12. Будут ли токены в логах?

Нет. В лог пишутся сообщения о ходе работы, ошибки и счётчики. Сами токены не выводятся.

### 13. Можно ли запускать только предпросмотр из командной строки?

Да:

```bat
glpi-cleaner-cli.exe --once --dry-run
```

или

```bash
python cli.py --once --dry-run
```

### 14. Что будет, если удалить папку logs?

Программа создаст её снова при следующем запуске. Старые файлы логов пропадут.

### 15. Можно ли поставить возраст «старше 0 дней»?

Минимальное значение в логике — 1. Для теста используйте Dry-Run и небольшой период (например, 1 day) только на тестовом GLPI.

### 16. Удаляются ли вложения вместе с заявкой?

При `force_purge` GLPI удаляет заявку и связанные объекты по своим правилам. Это необратимо. Без purge — поведение корзины GLPI.

### 17. Нужен ли интернет, если GLPI во внутренней сети?

Нужен доступ по сети до сервера GLPI (часто это корпоративная сеть/VPN), не обязательно «интернет целиком».

### 18. Можно ли использовать программу без графического интерфейса на Windows?

Да: кнопка «Запустить в фоне», или `glpi-cleaner-cli.exe --once` / `--daemon`, либо служба NSSM / Task Scheduler.

### 18a. Ошибка «Не найден glpi-cleaner-cli.exe»

Рядом с `GLPI_Cleaner.exe` должен лежать `glpi-cleaner-cli.exe` (оба из папки `dist` после сборки). Скопируйте оба файла и `config.json` в одну папку.

### 19. Что делать после смены пароля пользователя в GLPI?

User-Token обычно не меняется от смены пароля, но если ключ API перевыпустили — обновите User-Token в `config.json` и снова нажмите «Проверить подключение».

### 20. Где главная инструкция «с нуля»?

В файле [USER_GUIDE.md](USER_GUIDE.md).
