# Шпаргалка GLPI Cleaner (одна страница)

## Запуск

| Что нужно | Команда / действие |
|-----------|-------------------|
| Окно (GUI) | `GLPI_Cleaner.exe` или `python main.py` |
| Один прогон | `glpi-cleaner-cli.exe --once` / `python cli.py --once` |
| Только предпросмотр | `python cli.py --once --dry-run` |
| **Фон** (без окна) | GUI: «Запустить в фоне» **или** `glpi-cleaner-cli.exe --daemon` |
| Свернуть окно | GUI: «Свернуть в трей» |

## Остановка

| Где | Как |
|-----|-----|
| Фон из GUI | «Остановить фон» |
| Планировщик только в окне | «Остановить планировщик в окне» |
| Daemon в консоли | `Ctrl + C` |
| systemd | `sudo systemctl stop glpi-cleaner` |
| NSSM | `nssm stop GLPICleaner` |
| Docker | `docker compose stop` |
| Трей | правый щелчок → «Выход» |

## Где что лежит

| Что | Путь |
|-----|------|
| Настройки | `config.json` (рядом с программой) |
| Логи | `logs/glpi_cleaner.log` |
| PID фона | `glpi-cleaner-daemon.pid` (рядом с программой) |
| Документация | папка `docs/` |
| Главная инструкция | `docs/USER_GUIDE.md` |

## Три режима «фона»

1. **Запустить в фоне** — отдельный процесс CLI, окно можно закрыть  
2. **Трей** — то же окно скрыто, значок у часов  
3. **Служба / Task Scheduler** — для сервера (см. INSTALL_*)

## Три главные кнопки (GUI)

1. **Проверить подключение** — токены и URL верны?
2. **Предпросмотр (Dry-Run)** — что будет удалено?
3. **Запустить в фоне** — ежедневная работа без окна

## Три главных поля

1. URL: `https://…/apirest.php`
2. App-Token
3. User-Token

## Три частые ошибки

| Ошибка | Быстрое решение |
|--------|-----------------|
| 401 | Пересоздать/вставить токены |
| Нет связи / timeout | Проверить URL, VPN, файрвол |
| «Не найден glpi-cleaner-cli.exe» | Скопировать CLI-exe в ту же папку, что GUI |

## Безопасный порядок

1. Dry-Run = **вкл**
2. Предпросмотр → смотрим таблицу и журнал
3. Бэкап БД GLPI
4. Dry-Run = **выкл** (Force purge обычно **выкл**) → Сохранить
5. **Запустить в фоне**
