- Офис: Windows, домен **corp.willesden.by** (актуальный); **bmk.local** — устаревший.

## Категория «К сетевому ресурсу»

Не сектор, а согласование **СБ** перед выдачей доступа. Назначается **поверх** сектора-исполнителя.

**Без «К сетевому ресурсу»:** бейдж/пароль кассира, доступ к кассе (**САКПО** + **СПП** **всегда**); **добавление в рассылки Lotus**; УЗ Fusion **только для инвентаризации**; **доступ к диску X:** / **M:** (**СПП**; X/M доступны всем в AD, отличаются права; **САПО** — по эскалации от **СПП**). **С «К сетевому ресурсу»:** доступ **Fusion/1С**, **логин для работы на ТСД** (**СРИСиС**; [551774](https://support.willesden.by/front/ticket.form.php?id=551774)).

**С «К сетевому ресурсу»:** доступ к **itirsSTAFF** (итирсстаф) — **ОРПОиП**; ярлык `X:\PUBLIC FOLDERS\Ярлыки`, URL https://staff.bwd.by/; **новый** доступ к **SET10** — **САКПО** (восстановление SET10 — **сначала без** категории, см. **САКПО**)

## Категория «К финансовому ресурсу»

Согласование **финансового контура** (не сектор). Только для **доступа** к **«Заказы на оплату»** / **«Бюджеты»** **БВД/БМК** — **в Lotus** (подключение баз в клиенте).

**Порядок Lotus:** 1) **«К сетевому ресурсу»** → **СБ**; 2) **«К финансовому ресурсу»**; 3) **САПО** (+ **СПП**) выдаёт доступ.

**Bitrix24 «БП Финансы»** (оплаты, «Заказы на оплату в Bitrix», БП налоги/бюджет/справочники): **СПП** + **«К финансовому ресурсу»**, **без** «К сетевому» и **без САПО**; https://portal.willesden.by/note/document/15/

**Bitrix24 в тексте заявки:** **не** назначать группу GLPI **«Битрикс 24»**; категории — по сценарию, не «из‑за Bitrix».

**Не путать:** заведение контрагента в «Заказы на оплату» → **НСИ** (скан документа).

**Неинформативно:** «во все рассылки» без названий; «все доступы» без перечня; **«не работает принтер»** без типа/места — **«Заявка неинформативна.»**

**Принтеры:** документный **А4 / МФУ** (ремонт устройства, полосы на бумаге) → **СПОП** (Минск, Ярково, Мозырь, Островец, Сеница, Заславль, Боровляны) / **СОКС** (обл. центры); очередь печати на ПК → **СПП**; **URSA/TSC/чек** → **СОКС**.

**Касса vs кассир:** **кассир** (бейдж, пароль, доступ к кассам) → **САКПО+СПП**; **касса/чек зависли** (ПО) → **САКПО**; **заставка КСО / терминал / 914** → **СОКС** (если нет зависшего чека).

**Документ vs справочник:** акт, ТТН, отчёт в 1С → **СРИСиС**; карточка, ПСЦ, GTIN, ТНВЭД в карточке → **НСИ**.
